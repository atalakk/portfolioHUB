## 📋 Sobre o Projeto

O **portfolioHUB** é um portfólio pessoal desenvolvido com HTML, CSS e JavaScript puro, hospedado via GitHub Pages. O objetivo é apresentar minha trajetória acadêmica e profissional de forma clara e acessível para recrutadores, professores e colaboradores.

O projeto foi construído do zero, versionado com Git e publicado como parte do **Desafio Intermediário** da disciplina de Git & GitHub no Bootcamp de Engenharia de Software do UniCEUB.

---

## 🗂️ Estrutura do Repositório

```
portfolioHUB/

├── index.html          # Página principal do portfólio
├── style.css           # Estilos e layout
├── script.js           # Interações e animações

```

## 💼 Projetos em Destaque

### 🎵 Atala Amplify — Gestão Digital
Plataforma de operação de campanhas de promoção musical com análise de métricas de streaming, coordenação de entregas e relatórios de desempenho para artistas nacionais e internacionais.
- **Tipo:** Profissional
- **Ferramentas:** Excel Avançado, Google Analytics, gestão de stakeholders

---

### 🗃️ Modelagem de Banco de Dados
Projeto acadêmico de modelagem relacional com foco em normalização, entidade-relacionamento e criação de esquemas funcionais.
- **Tipo:** Acadêmico — Fundação Bradesco
- **Ferramentas:** Modelagem ER, SQL, normalização

---

### ☕ Algoritmos em Java
Exercícios e projetos práticos de lógica de programação com Java, cobrindo estruturas de controle, orientação a objetos e resolução de problemas algorítmicos.
- **Tipo:** Acadêmico — Fundação Bradesco
- **Ferramentas:** Java, POO, estruturas de controle

---

### 📊 Dashboard de Métricas — Freelance
Criação de planilhas avançadas em Excel com dashboards de KPIs para acompanhamento de desempenho de campanhas e projetos para clientes externos.
- **Tipo:** Freelance
- **Ferramentas:** Excel Avançado, Power Query, KPIs
